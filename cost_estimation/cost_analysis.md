# Cost Analysis — Round 1 Estimate

**Status of these numbers:** illustrative, based on the SilverTrust Brief Project client-interview exercise (Sept 2026), not an external published study. This is stated explicitly here and should be repeated in the presentation — see `sector_research.md` for the full transparency note.

## 1. Upfront cost — commercial options

Pulled from the original consulting deck's investment slide:

| Option | Indicative price | Best use |
|---|---|---|
| Paid pilot | €10,000 – €15,000 | One route, one product family (this is the Round 1 recommended scope) |
| Operational subscription | €2,000 – €5,000 / month | Ongoing validation & monitoring after the pilot |
| Custom implementation | €25,000 – €60,000 | More countries, more product categories |
| ERP / customs integration | Quoted after pilot | Connecting to I&E LLC's existing systems |

**Recommended ask for Round 1:** the paid pilot tier (€10,000–€15,000), scoped to one route and one product family, as detailed in `timeline_estimate.md`.

## 2. Expected monthly value (once running) — illustrative

| Value driver | Amount | Basis |
|---|---|---|
| Staff hours saved | €2,400 | 60 hours/month saved, at €40/hour |
| Avoided delay events | €3,000 | 2 avoided delays/month, at ~€1,500 each |
| Fewer correction/broker fees | €1,000 | Reduced rework and broker corrections |
| **Total illustrative monthly value** | **~€6,400 / month** | |

## 4. Break-even (illustrative)

Using the low end of the paid-pilot cost (€10,000) against the illustrative monthly value (€6,400):

**Break-even ≈ €10,000 ÷ €6,400/month ≈ 1.6 months** of full operation at the assumed value rate.

This is presented as a directional illustration, not a committed business case — the presentation should say so explicitly (see `evaluation/eval_plan.md` for the same honesty principle applied to test results).
